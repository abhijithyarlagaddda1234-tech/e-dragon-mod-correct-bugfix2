# Ender Dragon Overhaul 26.2 - fixed build

Fixes included:
- Dragon starts at 600/600 HP.
- Attack selection rotates so Laser/Orbs/Dive all get turns.
- Dive is driven across multiple ticks instead of one velocity push.
- Triple Dive is active from phase 2 onward.
- Laser now has a charge warning, visible beam, locked direction, damage and knockback.
- Tracking Void Orbs remain lightweight particle-based attacks.
- Adds a charged radial shockwave in later phases.
- Reduced unnecessary global entity scanning and particle spam.
- No Phantom crystal guardians.

Upload the CONTENTS of this folder into the root of your GitHub repo, replacing the old project files. Then open Actions -> Build Mod. The workflow also auto-runs after pushes to main.
